# Лабораторная 8 — теория для защиты

Клиентское хранилище Web Storage (`localStorage`), разделение логики
выбора и оформления заказа, позиционирование `position: sticky`,
отправка данных на сервер методом `POST` через `fetch`, авторизация
по `api_key` и обработка ответов.

## Что сделано в работе

1. Организовано сохранение выбранных блюд в `localStorage` по ключу
   `selected_dishes`. В хранилище сохраняются только идентификаторы
   блюд (`{ soup: id, main: id, ... }`), как требует задание.
2. Страница «Собрать ланч» (`lunch.html`) освобождена от формы заказа:
   вместо неё добавлена нижняя панель перехода к оформлению заказа
   (`checkout-bar`) с использованием `position: sticky`.
   - Панель скрыта, если ни одно блюдо не выбрано.
   - Ссылка «Перейти к оформлению» неактивна (`disabled`) до тех пор,
     пока состав не удовлетворяет комбо (ЛР 6).
   - При повторном открытии страницы сохранённый выбор восстанавливается
     из `localStorage`.
3. Создана страница «Оформить заказ» (`order.html`) с двумя разделами:
   - **Состав заказа**: карточки выбранных блюд с кнопкой «Удалить»
     (удаляет блюдо из DOM, пересчитывает сумму и обновляет
     `localStorage`). Если всё удалено, показывается заглушка
     со ссылкой на сбор ланча.
   - **Оформление заказа**: перенесённая форма с данными покупателя и
     пересчётом стоимости выбранных блюд («Не выбран» / «Не выбрано»).
4. Реализована отправка заказа на сервер `POST /labs/api/orders`:
   - Перед отправкой валидируется комбо.
   - Запрос уходит с персональным `api_key` в URL.
   - При успехе `localStorage` очищается, выводится подтверждение.
   - При ошибке выводится понятное сообщение, данные не сбрасываются.

## Web Storage API (`localStorage`)

- `localStorage` хранит пары ключ-значение в браузере бессрочно
  (пока пользователь или скрипт не очистит кэш).
- Доступ ограничен тем же источником (**Same-Origin**: протокол +
  домен + порт). Другой сайт не может прочитать данные.
- Данные сохраняются только в виде строк, поэтому объекты
  сериализуются через `JSON.stringify()` и десериализуются через
  `JSON.parse()`.
- Лимит хранилища обычно составляет около 5 МБ на origin.
- `sessionStorage` хранит данные только в рамках текущей вкладки,
  а `localStorage` сохраняется между вкладками и перезапусками.

## Позиционирование `position: sticky`

- Гибрид `relative` и `fixed`. Элемент находится в обычном потоке
  документа, пока не достигнет заданного смещения (например,
  `bottom: 0` относительно экрана/контейнера), после чего «прилипает».
- В отличие от `fixed`, sticky-элемент не выпадает из потока и не
  перекрывает другие элементы без учёта геометрии родителя.

## Отправка POST-запроса через Fetch

- `fetch(url, { method: 'POST', body: ... })` отправляет данные.
- В работе используется `FormData` (отправка `multipart/form-data`)
  или `JSON.stringify()` с заголовком `Content-Type: application/json`.
- В строке запроса всегда передаётся `api_key=...` для авторизации.
- Сервер возвращает JSON с созданным заказом либо объектом `{ error }`.

## Вопросы и ответы для защиты

1. **Почему в `localStorage` сохраняются только идентификаторы?**
   Хранение полных объектов избыточно: цены или названия могут
   измениться на сервере. Идентификаторы гарантируют актуальность
   данных при загрузке с API.
2. **Как передаются данные формы?**
   Через `fetch` методом `POST` с телом `FormData` или JSON, а
   ключ `api_key` передаётся в Query Parameters.
3. **Чем `localStorage` отличается от Cookies?**
   Куки ограничены 4 КБ и передаются на сервер с каждым HTTP-запросом.
   `localStorage` имеет объем ~5 МБ и доступен только на клиенте.
4. **Что происходит при нажатии «Удалить» на карточке блюда?**
   Блюдо удаляется из объекта заказа, обновляется `localStorage`,
   карточка исчезает из DOM, в форме статус меняется на «Не выбран»,
   а итоговая сумма пересчитывается.
5. **Как работает отключение кнопки перехода к оформлению?**
   Проверяется функция `isValidCombo()`. Если условия не соблюдены,
   вешается класс `.disabled` (`pointer-events: none; opacity: 0.7`)
   и атрибут `aria-disabled="true"`.
